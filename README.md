# Rain Craft Launcher

这是一个基于原始 PCL 代码进行二次开发/分支维护的 Minecraft 启动器项目。当前仓库为个人 fork，保留并遵守原始项目的许可证要求，未对原始代码、素材、许可声明和版权信息进行移除或替换。

## 项目简介

Rain Craft Launcher 是在原有 PCL 生态基础上进行定制与增强的启动器项目，目标是在保留原始功能与使用体验的同时，加入更多适合本项目使用场景的改动和扩展。
